# VK API Поиск постов: AI-восстановление семейных фото

Автоматический сбор постов из ВКонтакте по ключевым словам, связанным с использованием нейросетей для восстановления и создания семейных фотографий.

## 📋 Описание

Скрипт автоматически:
- Ищет посты по заданным ключевым словам
- Находит тематические группы
- Собирает информацию о постах, авторах, комментариях
- Создает структурированные карточки кейсов
- Сохраняет результаты в формате Markdown и JSON

## 🚀 Установка

### 1. Клонируйте репозиторий
```bash
git clone <repository-url>
cd VK
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Настройте токен доступа VK

#### Получение токена:
1. Перейдите на https://vkhost.github.io/
2. Выберите "VK Admin" или создайте standalone приложение
3. Получите токен с правами доступа: `groups`, `wall`, `offline`
4. Скопируйте токен

#### Создайте файл .env:
```bash
cp .env.example .env
```

Откройте `.env` и вставьте ваш токен:
```
VK_ACCESS_TOKEN=ваш_токен_здесь
VK_API_VERSION=5.131
```

## 💻 Использование

### Базовый запуск:
```bash
python vk_search.py
```

### Что происходит при запуске:

1. **Этап 1**: Поиск постов по ключевым словам
   - Использует метод `newsfeed.search`
   - Собирает до 50 постов на каждое ключевое слово

2. **Этап 2**: Поиск в тематических группах
   - Находит релевантные группы
   - Собирает посты из топ-10 групп по каждому запросу

3. **Этап 3**: Фильтрация и анализ
   - Удаляет дубликаты
   - Фильтрует по активности (лайки, комментарии)

4. **Этап 4**: Создание карточек
   - Анализирует каждый пост
   - Извлекает мотивацию, процесс, результат
   - Формирует структурированные карточки

### Результаты:

Файлы сохраняются в папку `results/`:
- `results.md` - карточки кейсов в формате Markdown
- `results.json` - структурированные данные в JSON

## ⚙️ Настройка

Отредактируйте `config.py` для изменения параметров поиска:

```python
SEARCH_CONFIG = {
    'posts_per_keyword': 50,  # Постов на ключевое слово
    'groups_per_query': 20,   # Групп на поисковый запрос
    'posts_per_group': 100,   # Постов из одной группы
    'min_likes': 0,           # Минимум лайков
    'min_comments': 0,        # Минимум комментариев
}
```

Добавьте свои ключевые слова:
```python
SEARCH_KEYWORDS = [
    'ваше ключевое слово',
    # ...
]
```

## 📊 Структура карточки кейса

Каждый найденный пост преобразуется в структурированную карточку:

```markdown
## КЕЙС [номер]

**Источник:** [URL поста]
**Автор:** [имя пользователя/группы]
**Дата:** [дата публикации]
**Платформа:** VK

**Контекст:**
- Информация об авторе (локация, профессия если доступно)

**Мотивация:**
- Извлеченная мотивация из текста

**Процесс:**
- Использованные технологии (Midjourney, DALL-E и т.д.)

**Результат:**
- Описание результата

**Рефлексия автора:**
- Эмоциональный отклик автора

**Социальный контекст:**
- Статистика: лайки, репосты, комментарии
- Примеры комментариев

**Медиа-логика:** Дополнение / Трансформация / Рекомбинация

**Цитаты (ключевые):**
> [текст поста]
```

## 🛠 Технические детали

### API лимиты:
- Максимум 3 запроса в секунду
- Скрипт автоматически контролирует частоту запросов

### Используемые методы VK API:
- `newsfeed.search` - поиск постов
- `groups.search` - поиск групп
- `wall.get` - получение постов со стены
- `wall.getComments` - получение комментариев
- `users.get` - информация о пользователях
- `groups.getById` - информация о группах

## 🔧 Устранение проблем

### Ошибка: "VK_ACCESS_TOKEN не найден"
- Убедитесь, что создан файл `.env`
- Проверьте, что токен скопирован правильно

### Ошибка: "Too many requests per second"
- Скрипт автоматически управляет лимитами
- Если ошибка повторяется, увеличьте задержки в коде

### Ошибка: "Access denied"
- Проверьте права доступа токена
- Убедитесь, что токен не истек

## 📈 Критерии завершения сбора

Поиск считается завершенным когда:
- ✅ Найдено минимум 5-7 русскоязычных кейсов
- ✅ Достигнуто разнообразие по:
  - Типам мотивации (утрата, исследование, терапия)
  - Типам технологий (Midjourney, DALL-E, Stable Diffusion)
  - Степени рефлексивности
